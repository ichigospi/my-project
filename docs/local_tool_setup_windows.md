# 台本読み取りツール セットアップ手順（Windows・管理者向け）

これを一度セットアップすると、オーナーからURLをもらわなくても、
**自分のPCでいつでも読み取りツールを起動できる**ようになります。

所要時間: 初回のみ15〜20分（2回目以降はダブルクリックだけ）

---

## 手順1: zipを展開して配置（初回のみ）

オーナーからもらったzipを右クリック →「すべて展開」で解凍し、
出てきた `fortune-yt-tool` フォルダを分かりやすい場所（例: `C:\Users\自分の名前\fortune-yt-tool`、
デスクトップでも可）に置いてください。

※zipに接続設定（.env.local）が含まれている場合、初回のキー入力は不要です。
　含まれていない場合は、オーナーから「データベースURL・トークン・AIキー」の3つをもらっておいてください。

## 手順2: 必要ソフトのインストール（初回のみ）

スタートボタンを右クリック →「ターミナル」（または「Windows PowerShell」）を開き、
以下を**1行ずつ**コピペしてEnterで実行します。

### 2-1. Node.js

```
winget install OpenJS.NodeJS.LTS
```

### 2-2. yt-dlp（動画ダウンロード用）

```
winget install yt-dlp.yt-dlp
```

### 2-3. ffmpeg（動画処理用）

```
winget install Gyan.FFmpeg
```

3つとも終わったら、**ターミナルをいったん閉じて開き直し**、確認:

```
node -v
```

`v20` 以上の数字が出ればOKです。

※`winget` が無いと言われた場合は、Microsoft Storeで「アプリ インストーラー」を入れるか、
　各公式サイト（nodejs.org / yt-dlp / ffmpeg）から手動インストールしてください。
　yt-dlp.exe と ffmpeg.exe を手動で入れる場合は `C:\Windows` に置くのが簡単です。

## 手順3: 起動

`fortune-yt-tool` フォルダを開き、**`start-local.bat` をダブルクリック**。

- 「WindowsによってPCが保護されました」（SmartScreen）と出たら、
  **「詳細情報」→「実行」** をクリック（初回だけです）
- 初回は自動でパッケージのインストールが走るので数分待ちます
- .env.local が無い場合のみ、もらった3つのキーを聞かれるのでコピペで入力

起動が終わると、自動でブラウザに読み取り画面（ `http://localhost:3000/ocr` ）が開きます。

**2回目以降は `start-local.bat` をダブルクリックするだけです。**
（黒いウインドウは閉じずにそのまま。閉じるとツールが止まります）

---

## 更新のしかた

オーナーから「ツールを更新して」と言われたら:
- zipで導入した場合: 新しいzipをもらい、古いフォルダを丸ごと入れ替え
  （※入れ替え前に、旧フォルダの `.env.local` をコピーしておき、新フォルダに戻すとキー再入力不要）
- git導入の場合: `update-local.bat` をダブルクリック

---

## うまくいかないとき

| 症状 | 対処 |
|---|---|
| SmartScreenで実行できない | 「詳細情報」→「実行」 |
| `Node.js not found` と出る | 手順2-1を実行後、PCを再起動してから再度ダブルクリック |
| yt-dlp / ffmpeg の警告が出る | 手順2-2、2-3を実行してターミナルを開き直す。ダメなら exe を `C:\Windows` に置く |
| 動画のダウンロードに失敗する | ターミナルで `winget upgrade yt-dlp.yt-dlp` を実行して起動し直す。直らなければエラー画面のスクショをオーナーへ |
| AIエラー（クレジット・APIキー系） | オーナーに連絡（APIクレジットの問題です） |

分からないことがあれば、エラーが出ている画面のスクショをオーナーに送ってください。
