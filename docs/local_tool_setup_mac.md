# 台本読み取りツール セットアップ手順（Mac・管理者向け）

これを一度セットアップすると、オーナーからURLをもらわなくても、
**自分のMacでいつでも読み取りツールを起動できる**ようになります。

所要時間: 初回のみ15〜20分（2回目以降はダブルクリックだけ）

---

## 事前にオーナーからもらうもの（3つ）

セットアップの途中で入力するので、先にもらっておいてください。
※秘密情報なので、受け渡しは信頼できる連絡手段で。

1. **データベースURL**（`libsql://` で始まる文字列）
2. **データベーストークン**（長い英数字）
3. **AI APIキー**（`sk-ant-` で始まる文字列）

あわせて、プロジェクトの受け取り方も確認してください（下の手順2）。

---

## 手順1: 必要ソフトのインストール（初回のみ）

「ターミナル」アプリを開き（⌘+Space →「ターミナル」で検索）、
以下を**1行ずつ**コピペしてEnterで実行します。

### 1-1. Homebrew（Macのソフト管理ツール）

```
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
```

- 途中でMacのパスワードを聞かれたら入力（画面に文字は出ませんがそのままEnter）
- 最後に「Next steps」として2行のコマンドが表示されたら、**その2行もコピペして実行**
  （`echo >> ~/.zprofile` と `eval "$(...)"` のような行です）

### 1-2. Node.js / yt-dlp / ffmpeg

```
brew install node yt-dlp ffmpeg
```

数分かかります。終わったら確認:

```
node -v
```

`v20` 以上の数字が出ればOKです。

---

## 手順2: プロジェクトを自分のMacに置く（初回のみ）

オーナーの案内に応じて、どちらかの方法で。

### 方法A: GitHubから取得（おすすめ・更新がラク）

オーナーからGitHubリポジトリへの招待を受けたら（メールが届きます）、承認後にターミナルで:

```
cd ~
git clone https://github.com/ichigospi/my-project.git fortune-yt-tool
```

- GitHubのユーザー名とパスワードを聞かれたら、パスワード欄には
  GitHubの「Personal Access Token」を入力します（作り方はオーナーに確認）

### 方法B: zipで受け取る

オーナーからもらったzipを解凍し、フォルダ名を `fortune-yt-tool` にして
「ホーム」フォルダ（Finderで ⌘+Shift+H）に置きます。
※この方法は更新のたびにzipをもらい直す必要があります

---

## 手順3: 起動（初回セットアップ込み）

Finderで `fortune-yt-tool` フォルダを開き、**`start-local.command` をダブルクリック**。

- 初回は「開発元を確認できないため開けません」と出ることがあります。
  その場合は **右クリック → 開く → 開く** で起動できます（2回目以降は普通にダブルクリックでOK）
- 初回起動時に、事前にもらった3つ（データベースURL・トークン・AIキー）を聞かれるので、
  コピペして入力してください（1回入力すれば保存されます）

起動が終わると、自動でブラウザに読み取り画面（ `http://localhost:3000/ocr` ）が開きます。

**2回目以降は `start-local.command` をダブルクリックするだけです。**

---

## 更新のしかた

オーナーから「ツールを更新して」と言われたら、
**`update-local.command` をダブルクリック**するだけです（方法Aで導入した場合）。

---

## うまくいかないとき

| 症状 | 対処 |
|---|---|
| 「開発元を確認できない」で開けない | ファイルを右クリック → 開く → 開く |
| `brew: command not found` | 手順1-1の「Next steps」の2行を実行し忘れています。ターミナルを開き直して再実行 |
| 画面上部に黄色い警告（yt-dlp/ffmpegが無い等） | `brew install yt-dlp ffmpeg` を実行して起動し直す |
| 動画のダウンロードに失敗する | ターミナルで `brew upgrade yt-dlp` を実行して起動し直す。直らなければエラー画面のスクショをオーナーへ |
| AIエラー（クレジット・APIキー系） | オーナーに連絡（APIクレジットの問題です） |

分からないことがあれば、エラーが出ている画面のスクショをオーナーに送ってください。
